## 1. 目标、决定与边界

将现有完整制作能力整理为“羊番TV”统一界面：从项目与分集进入，以 Agent 对话和画布组织创作，完成剧本、镜头、声音、剪辑和交付。首页具有品牌和立体作品画廊，工作区轻量、清楚、适合持续操作。不能为减少入口或追求图稿效果删去已有功能。

用户始终知道正在操作哪部短剧、哪一集、哪个版本；输入、准备、批准、执行、审核、采用、交付各阶段影响明确。

### 1.1 用户已明确

- 品牌准确写作 **羊番TV**；原创羊羊机器人保留浅色羊毛／外壳、卷角、深色脸屏与亮色眼睛。
- 黑蓝主背景、侧栏蓝紫渐黑；蓝色为主要交互强调，渐变轻、局部、有层次。
- 首页保留中央横幅与两侧倾斜海报的立体画廊，支持手动和自动切换。
- 导航、任务、设置使用精致实心图标；艺术字用于品牌、首页重点和影片标题。
- Composer参考即梦、小云雀的连续输入面和展开工具，避免僵硬表单及按钮块堆叠。
- 排除土黄／奶油主底、整块浅色选中、银色金属倒角按钮、霓虹外框、重玻璃套卡和悬浮场记板。

### 1.2 已采用方案

五主入口为“项目／创作／制作／资产／成片”，任务与设置在全局底部；创作包含共享会话的对话／画布视图。导航默认展开或紧凑仅由窗口宽度决定，用户手动选择优先；切换工作区或子页不得改变导航宽度、品牌、字号、图标尺寸和按钮位置。

先实施统一骨架和首页，再逐页迁移，沿用现有引擎与契约。只改变展示品牌；内部包名、appId、profile目录、项目清单标识和API命名保持兼容。

### 1.3 非目标

不新增Linux／远程引擎、多人协作、云账户、支付、广告、商城、自动发布、新模型供应商、Agent自主递归执行或任意多模态理解。不扩大SPEC-003容量，不重写存储与生成引擎。本次实施授权来自用户“开始实现spec005”；不包含付费验证或发布。

## 3. 方案与取舍

| 方案 | 取舍 | 结论 |
| --- | --- | --- |
| 十入口只换皮 | 改动少，但Agent／画布／分集／声音仍分散 | 不采用 |
| 五入口，复用业务组件、逐页迁移 | 统一路径并保留审批恢复，需要导航适配和组件拆分 | 本稿推荐 |
| 重建前后端或嵌入第三方平台 | 数据风险大，偏离本机边界 | 不纳入 |

允许拆分业务控制器与展示组件，沿用contracts、runtime及服务；仅为布局、预览和草稿增加renderer状态，不建立第二套业务数据库。

| 类型 | 初值／规则 |

| 侧栏 | #222D4C经#172139至#0C111C，局部低透明蓝紫光 |

正文用本地中文系统字体栈；品牌和首页用有许可字体或原创字标，普通工具不斜体。正文对比度≥4.5:1，大字／关键图形≥3:1；校验混合后的真实颜色，包括蓝底白字。

### 5.2 组件合同

- 导航：实心轻量，选中深色底＋蓝图标或短标记；有悬停、焦点、当前页、禁用、徽标。
- 按钮：每局部操作区最多一个高强调主动作，次操作文字或低对比表面；不持续发光。
- 分集／版本：同底色、短线或单一边界；预览和采用标志分开。
- Composer：一个连续表面；正文、引用、底部工具层次清楚；实际添加后才有附件缩略图。
- 菜单：当前值、范围、限制可见；键盘可达，Esc关闭回焦点，长内容内部滚动。
- 结果流：正文直接排版；媒体来自真实结果；差异／来源可展开；采用靠近明确目标。
- 详情：大预览＋窄信息栏；无双主标题、重复选中装饰。
- 状态：真实进度才显示百分比，否则不确定进度；未知结果单列。
- 空／错误：原位置说明原因与下一步，保留输入，不放假项目／假任务。

### 5.3 尺寸与动效

逻辑视口≥1280px：所有工作区统一默认226px展开导航，手动紧凑为64px；首页保留30px左内容边距，其余页边距24px。1024–1279px默认64px紧凑，手动展开为176px，检查器可覆盖；800–1023px保持64px导航，单主面板＋切换辅助面板，首页任务纵排。导航选择在工作区、子页、任务和设置间保持，已保存的手动选择在重开时继续生效。不得提高现有主窗口800×560 DIP最小尺寸掩盖问题；初始1180×780，依据main/workbench.ts。测实际内容区，不能把外框当内容区。

仅画布、时间线、镜头条等专用容器允许横向平移／滚动。控件反馈120–180ms、详情180–240ms、画廊420ms，优先transform／opacity，正文不持续漂浮。

画廊自动间隔6秒；悬停、焦点进入、拖动、窗口隐藏暂停。手动切换重置计时，显式暂停保留至本次会话结束；单卡不轮播；prefers-reduced-motion停自动并移除空间转场。


## 6. 页面流程与交互合同

### 6.1 首页、画廊与分集

画廊选择的是**预览项目**，当前制作上下文独立。自动／手动浏览均不得改变实际项目、分集、镜头、画布或输入草稿。明确“继续制作／打开项目”后，经草稿保护及已有打开机制进入目标。

**数据边界：**首批工作台画廊只读取当前引擎project.list可见项目。目录模式通常只有一部短剧，此时显示真实单卡；不能为凑齐四张图读取其他项目数据库。其他目录继续从启动器打开。本规格不新增跨目录封面缓存／跨引擎聚合；多卡效果以隔离多项目fixture验证；首页视觉交付必须默认展示四张各自有封面的项目，不能用单卡fixture替代已选图的立体画廊验收。真实工作目录仍保持真实项目数量。若用户要求工作台直接预览全部最近短剧，需先扩充只读桥接合同与本节，不能默默跨目录访问。

封面使用该项目可解析的既有固定媒体引用，缺失时原创默认封面＋真实名称；每个可见项目分别以自己的projectId/subprojectId查询封面，不能只给工作项目配图；首次选中当前工作项目，未选中项目的预览不发出写命令。第一期不新增封面编辑后端字段。不能偷偷生成封面。目录模式“新建短剧”打开启动器，旧资料库模式沿用project.create。

分集条、继续位置、待办与任务摘要属于当前工作项目，不随画廊预览变化。待审核／运行数量来自实际对象，无法可靠统计则省略。无分集引导创建；无项目不注入演示数据。

分集管理保留名称／编号、归档恢复、多画布、主时间线、前期来源与锁定版本、完成摘要编辑撤回。标记完成沿用自动记忆机制，显示所用文本模型与同步状态；浏览不触发模型调用。

### 6.2 创作：Agent与画布

1. 首页输入保存在当前项目／子项目的首页草稿；进入创作后绑定明确会话。无会话时显式创建，不静默发到旧会话。
2. 工具为+、@、模式、技能、模型、偏好，按真实能力展示。+选择既有素材或调用现有导入；@选择剧本、同剧本镜头、实体、固定素材引用，不拿名称字符串代替身份。
3. 模式为all／script／director，现有会话创建后固定。换模式新建会话，可显式带入未提交文本，不能改写历史。
4. 技能映射模板与版本；模型映射可用的应用级文本预设；偏好含输出预算、上下文和修改目标。比例／分辨率／时长仅放在支持它们的生产设置。
5. 发送按钮的可访问名称为“准备这一轮规划”，相邻提示解释该动作。准备只冻结目标、配置、预算与引用；明确批准才提交模型；收取提案后展示差异，明确采用后才更新作品。
6. 对话与画布侧栏共享会话控制器和Composer草稿，切换保留文本、引用、选择和滚动。隐藏页卸载不必要媒体，不停止后台持久任务。
7. 画布保留节点、参数、连线、版本、工作流和单次批准；提案采用成功后才增改内容，预览候选不自动填满画布。

使用真实textarea或等价可靠编辑控件。Enter换行、Ctrl+Enter准备；中文输入法组合期间不提交。空输入、超限、无模型、离线或未知回执禁发并在附近解释。上限沿用契约，不能复制旧图“300字”等装饰数字。

按真实PREPARED／PLANNING／PROPOSED／REPLIED／INVALID／FAILED／UNKNOWN／STOPPED／ACCEPTED映射状态。停止说明实际停止层次，不保证云端费用已取消。媒体来自实际任务固定结果，不把文字提案伪装成视频生成成功。

### 6.3 制作：剧本、镜头、对白

剧本保留正文、场景、修订和保存。镜头视图含资产／引用列、可编辑信息、大预览、底部镜头条；窄窗口切换参数／预览，保存与主要生成动作可见。

画面、景别、运镜、时长有默认、悬停、聚焦、脏草稿、保存中和冲突状态。资产默认“全部”；“角色”只能列角色。草稿保存、镜头审核、生成批准、生成完成、候选采用分别表示。

保留首帧／参考与外部图复用：合法外部图可直接用于视频准备，无须图像模型补图。每批最多16镜头；部分成功保留、失败明确重试、未知先核对原任务。

对白保留角色声音修订、台词、试镜、生成、审核、口型修复、组装和恢复。不能把声音能力缩减成角色图片卡；候选展示来源、版本和采用目标。

### 6.4 资产：媒体、实体与声音

媒体类型筛选（图片／视频／音频／文本）与来源筛选（当前子项目／共享／全部成果／未分类）独立。保留现有默认all。公共分类不是访问权限；角色／场景／声音保留语义身份及修订，不全转为媒体卡。

详情区分浏览版本、目标镜头／节点固定引用版本、其他历史版本。缩略图点击只变预览；加入画布、作参考或替换目标需要明确动作，展示目标与版本。兄弟集素材可固定引用，跨父项目须明确导入。

无引用显示空关系；文件缺失禁用采用并提供定位／重新导入入口；无假预览。导入、归类、回收、恢复沿用现有业务。外部来源字段只作声明；声音详情保留试听、档案状态和使用关系。

### 6.5 成片

现有[FinishPanel／FinishProposal](../../libtv-studio/apps/desktop/src/renderer/features/agent/FinishProposal.tsx)使用独立[finish.*合同](../../libtv-studio/packages/contracts/src/finish-agent.ts)。成片页提供“成片助手”入口，创作页保留同一功能的跳转；沿用明确的sessionId和应用文本预设；无会话时选择或显式建立当前集会话，不另建无关联会话。支持voice-lines配音文案、subtitle-edits字幕修订、rough-cut粗剪三类提案，各自prepare→approve→accept，使用FinishTemplate，不塞入普通AgentTemplate。粗剪最多32镜头及32素材，配音文案目标最多16镜头／16文案，字幕最多100条；从各自契约校验。采用只修改本地文案、字幕或时间线，不自动配音、识别或渲染。普通Composer的8项参考限制不得降低这些既有上限。

结构为命名时间线、固定剧本修订、保存／撤销／重做、画面／配音／音乐／字幕四轨、预览、属性与本地作业。保留粗剪、代理／正式预览、字幕、音频、修订恢复和多制品。

未保存剪辑与已保存修订分开。导出固定已保存修订，展示MP4／WAV／SRT／CSV／原件ZIP、位置与预算；原导出核对和仅重试复制有独立入口，不能用云端重生成解决导出失败。成功后按既有规则登记制品。

沿用SPEC-003：画面256段、配音／音乐各256段、字幕1000条、600秒、JSON 1MiB、编辑100op、生成批次16、代理每批64引用、原件ZIP 2GiB；其他输出／磁盘上限仍由原合同控制。达到上限仍能删改，不静默截断；2／4／8GiB中间预算与30分钟导出执行／核对总预算不回退。

### 6.6 任务、设置、启动器

任务按本集／本项目聚合，无子项目使用已有可用范围。真实来源和阶段可见；来源跳转走导航保护。区分生成、记忆、媒体处理与导出；不能用顶部两个示例任务冒充全部任务。

模型、连接和预设属于应用，密钥仍只在独立窗口输入，不返回工作台或项目文档。MCP保留实例／作用域、来源白名单、requestId、epoch与批准。备份、恢复、迁移和升级辅助进入现有启动器流程。

界面品牌、窗口标题、导航、启动器、设置统一羊番TV；内部ID、旧路径、回执和键名不批量替换。安装器／可执行文件更名不在首批范围，另需升级兼容验证。

## 7. 数据、状态与恢复不变式

| 条件 | 要求 |
| --- | --- |
| 导航／跨集 | 可保存编辑仍保存／放弃／取消；未提交Agent输入为保留草稿后切换／放弃／取消，保留仅限renderer会话，不冒充磁盘保存 |
| 同会话对话↔画布 | 共享文本／引用，保留选择／滚动，不重复建会话或提交 |
| 作用域变化／迟到 | 查询键带libraryId、epoch、projectId、subprojectId；结果回原来源，不覆盖当前页 |
| 离线／ACK_UNKNOWN | 留草稿、停新写入、核对原回执；重开／换tab不能绕过 |
| UI偏好或选择失效 | 回到可用视图，只处理无效UI选择，不删业务数据 |
| 退出／重载 | 沿用保存和关闭保护；画布及新Composer内存草稿不保证跨重启 |
| 归档／删除／回收 | 保留引用和恢复规则；显式动作才修改，任务仍归原子项目 |
| 未知／部分成功 | 独立状态，保留成功结果；先核原请求，不整批无差别重发 |

业务事实来自引擎和contracts；project／subproject／canvas／session／shot／timeline身份独立。UI状态仅含目的视图、面板、预览版本、滚动、画廊索引和未提交Composer。可持久化外观偏好用版本化UI key；不存Key、原件或第二份任务事实。

继续遵守[SPEC-001](../001-character-voice-consistency/spec.md)声音身份、[SPEC-002](../002-project-subprojects/spec.md)固定版本与连续创作、[SPEC-003](../003-production-reliability-and-capacity/spec.md)容量与恢复、[SPEC-004](../004-mcp-external-assets/spec.md)外部资产。批准后本规格替代相冲突的旧UI方向，不替代业务合同。
