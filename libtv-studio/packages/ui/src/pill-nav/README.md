# 羊番 Pill Nav

Adapted from [React Bits Pill Nav](https://reactbits.dev/components/pill-nav),
[official TS/CSS registry](https://reactbits.dev/r/PillNav-TS-CSS.json), retrieved 2026-11-08.
Copyright (c) 2026 David Haz. MIT + Commons Clause; full notice in LICENSE.md.

The original leading/trailing-edge spring integration is retained. The app adapter
uses a controlled selection, a dark pill, decorative image slots, manual keyboard
activation, disabled items, reduced motion, resize measurement and visibility cleanup.
Logo, mobile menu, intro, fill/rolling labels and white-pill presets are omitted.
No new dependency. The selected value changes only when the existing navigation guard commits.

Original tab decoration images were generated with built-in image_gen, 2026-11-08.
Prompts and source filenames are recorded in assets/prompts.json. They are decorative,
not navigation icons or copies of Jimeng's brand mark.
