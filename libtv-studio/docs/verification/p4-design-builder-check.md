# P4 方案可实施性检查

日期2026-10-27。对象：`docs/superpowers/specs/2026-10-27-p4-audio-timeline-design.md`及同日技术核对。检查方式：独立新上下文只读审查，报告会影响实现的未决问题；未执行产品、测试、模型请求或安装。

检查者提出4个问题。控制器核对既有设计和实现边界后作出以下设计选择，并同时写入设计/实施计划；这些是本次建议，未冒称用户逐项选择。

| 问题 | 已写入的决定 | 代价与验证 |
| --- | --- | --- |
| 波纹删除遇到跨区间声音/字幕 | 四轨按同一时间区间切除；交叠内容裁切或拆分，后段源入点跳过被删内容；字幕保留文字并提示受影响项 | 会切掉BGM的一段并可能产生字幕碎段；Task2用10–15秒删除例子检查，超片段数整批拒绝，用户可撤销/改字 |
| 成片长度及末尾删除 | 取全部轨道末端最大值并向上对齐帧；音乐长于视频出现提示黑场；末尾内容删除后缩短 | 用户需主动裁切过长音乐；空时间线不可渲染，纯音频只WAV；Task2/4验证 |
| 帧率归属和更改 | 每条时间线独立fps，非空后锁定；改变帧率需新时间线 | 首版不能原地转换已有剪辑，避免隐式重吸附；Task2测试空/非空setSettings |
| MP4/WAV共同计划还是独立计划 | 固定合成快照可共享compositionHash，但用途各自生成planHash/job并分别确认 | 输出两种格式需两次明确操作；可独立失败/取消/重试，Task4/5验证 |

检查者认为其余运行时固定、字体验证、媒体共同起点、许可资料、队列恢复和Agent批准边界足以进行规划；不需要再向用户追问这些技术问题。本轮没有追加无止境审阅循环。

控制器另做计划自查：8个任务覆盖设计范围；Review Focus五类风险都落到测试；默认24,000,000字节ASR上限与24MiB不同；派生预览有独立引用及显式入队；MP4/WAV不暗中互相触发；模型调用/本机处理/目录复制的恢复责任分开。当前仅文档完成，不代表上述测试已执行。
