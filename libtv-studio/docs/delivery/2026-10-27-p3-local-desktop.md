# MovieAgent P3 本机使用说明

2026-10-27：最终复核通过，交付入口已指向 `release-p3`。已有运行窗口保持运行，用户项目和模型配置未用于开发测试。

## 打开

退出旧 MovieAgent 窗口后，双击 `D:\movieAgent\启动MovieAgent.cmd`。在项目启动器打开已有短剧目录，或创建新的短剧项目。升级资料库时沿用现有备份机制。

软件模型配置仍在 `D:\movieAgent\libtv-studio\config\models.json`，也可通过「模型设置」管理。已保存的模型不需要因为 P3 重填。

## 创作与生成

1. 在「创作 Agent」创建会话，选择模式、模板、文本预设和需要的上下文，填写需求。
2. 预览并批准这一次文本规划的参数与预算。模型完成后查看提案；已有内容提供修改前后对比。
3. 勾选需要的镜头或实体并采用。每轮采用一个明确子集，重复点击沿用原回执；未采用的部分可在新轮次继续提出。
4. 在「剧本分镜」编辑剧本、场景和镜头；在「角色场景」维护角色、场景、道具、风格与固定素材引用。
5. 选中镜头，选择图像/视频预设，预览实际参数及引用，然后确认布置到画布。再批准媒体执行计划，任务才会提交。
6. 从镜头结果查看图片、视频、任务与生产历史，可手动选用旧结果。旧结果会保留原始生成版本；停止后迟到的产物不会覆盖手动选择。

一次制作最多选择 16 个镜头、32 个生成步骤。超出模型时长或参考素材能力时会明确报错。重新生成会保留历史。

## 导出和恢复

「剧本分镜」中的「导出 JSON」「导出 Markdown」将快照保存到当前短剧目录的 `exports/creation`，保留固定实体修订。导出不会覆盖已有文件，也不会自动同步起始模板。

重开项目只恢复已有任务和记录，不自动再发一次规划请求。遇到版本冲突先重读内容或发起新提案；遇到未知提交可查看原任务，不把重新生成当作无成本重试。

## 验证边界

P3 的流程使用本地 HTTP 模拟服务和临时目录验收。测试截图中的色块、视频色条是验证素材，不是真实模型作品。用户真实 Kimi 的长篇结构化提案和真实图像/视频组合仍需后续有限验收。

Agent 使用受控 JSON 提案；图片和视频上下文只提供元数据。当前导出是创作资料快照，MP4 剪辑成片属于后续 P4。安装包是未签名本机测试版，签名与干净 Windows 安装未验收。
