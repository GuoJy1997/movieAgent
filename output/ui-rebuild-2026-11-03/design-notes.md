# MovieAgent「纯白中性工作室」UI 概念图说明

日期：2026-11-03。目标交付范围：18 张完整界面概念图及本说明。

**版本关系：本版替代 2026-11-02 被用户否决的暖底草稿。** 用户明确拒绝米黄、土黄背景；旧文档与图保留作为历史，不再作为当前视觉依据。

这是本轮视觉交付物的说明，不是新的权威需求规格，不替代工作区 spec/ 中的既有规格。页面组织、视觉和动效均为重构建议；本轮未实现产品界面，也未验证真实交互。图中的作品、封面、文案与任务数据是演示内容。

## 1. 视觉方向与硬约束

采用纯白、中性灰与墨色建立干净的电影制作工作室。大幅作品画面、开阔的编辑区、清楚的栏目和有辨识度的封面承担视觉重点。保留浮岛导航与编辑式构图；应用界面不再使用上一稿的暖色材质。

| 用途 | 固定色值 | 使用规则 |
| --- | --- | --- |
| 应用主背景 | 纯白 #FFFFFF | 页面和主要编辑空间保持纯白，禁止偏黄白色 |
| 次级面板与分区 | 中性灰 #F5F6F8 | 用于浅层分区，不染成奶油色、暖灰或纸色 |
| 主要文字与图标 | 墨色 #121316 | 普通正文、控件和导航保持清晰 |
| 选中与主要交互 | 蓝色 #2D61E8 | 少量用于当前入口、主要动作和明确选中态 |
| 视频预览与轨道 | 中性暗色 #111214 | 仅重点影像工作区使用，不能带棕色或黄色暗调 |

**禁止纸纹、米白、米黄、土黄、暖调底色、做旧材质与复古滤镜。** 不给整张UI或作品画面统一套暖色滤镜；真实素材自身的色彩与界面底色分开处理。所有生成提示词和人工检查均以这条为硬约束。

- **画面主导**：项目入口与总览使用大幅作品场景；生产工作台保留足够编辑面积。同一演示作品的角色、场景和封面保持一致。
- **字体**：普通控件、导航、表单、正文和时间码使用干净的无衬线字体；目录级展示标题可以少量使用衬线字体，不能扩散到密集业务界面。
- **空间层次**：用留白、细线、字重、比例和中性面板建立层级；避免重复卡片、发光边框、密集小标签及大面积彩色渐变。
- **明暗分工**：外壳和大多数工作区保持浅色；剪辑预览和轨道使用中性暗色，保证播放画面和时间关系集中显现。
- **状态**：保留文字及必要图标，不能仅靠颜色判断完成、错误、未知或正在运行。

## 2. 导航重构

移除固定应用侧栏。顶部采用浮岛胶囊导航，分为「项目／创作／制作／素材／成片」。任务和设置入口固定在右上方。顶部同时保留明确的项目、当前集期和必要的画布或时间线范围。

组内局部导航放在顶部主导航下方，使用明确文字；所处位置持续可见。全局分组变化不改变现有业务范围，切换集期也不应使正在执行的任务转到另一集。

| 旧入口／当前功能入口 | 新组／位置 | 对应页面与局部入口 |
| --- | --- | --- |
| 项目启动器 | 独立启动窗口 | 01 启动器；项目维护作为可展开工作区 |
| 项目 | 项目 | 02 项目资料库 |
| 分集与分期 | 项目 | 03 分集、集期管理、项目记忆、连续创作与制品 |
| 创作 Agent | 创作 | 05 创作会话、提案审阅、成片助手 |
| 剧本分镜 | 创作 | 06 剧本与分镜；镜头生产和对白入口继续可达 |
| 画布 | 制作 | 04 自由画布；显示当前画布选择 |
| 选定镜头制作／结果历史 | 制作 | 07 镜头生产与结果挑选 |
| 对白制作／口型审核／修复 | 制作 | 08 对白、审核、修复与逐句装配 |

| 剪辑成片 | 成片 | 12 时间线；13 声音与字幕；14 导出与交付 |

「镜头生产」「对白」「声音」「导出」等是已有功能的新展示组织，不代表当前源码已经有这些独立路由。

## 4. 关键组件、状态和操作规则

| 组件 | 状态和操作 | 键盘／缩窄规则 |
| --- | --- | --- |
| 顶部胶囊导航 | 当前组有文字、底色和位置提示；右上任务可显示未完成数量 | 每个入口可 Tab 聚焦并用 Enter 激活；窄窗口可收成带文字的组选择器，不只留无解释图标 |
| 项目／集期范围 | 显示当前项目、集期及对象；选择后更新相关页面内容 | 焦点可达；下拉列表保持当前值和明确标签，长名称可截断但能查看全文 |
| 页面局部导航 | 保留功能名称及当前页；不让重要功能只能通过悬停出现 | 使用按钮或真实标签语义；标签组按实际组件遵循方向键规则 |
| 编辑工作区 | 区分已保存、未保存、保存中、冲突和离线；离开脏草稿有明确处理 | 主编辑区优先；窄窗把辅助检查器改为可打开抽屉，不能挤没正文 |
| 媒体卡与预览 | 图片、视频、声音有类型；显示采用状态与来源版本 | 预览和选择为独立动作；大图保留完整预览入口，焦点不依赖缩略图悬停 |
| 审核与采用 | 质量结论和采用动作分开；保留原版本与当前选择 | 审核项可逐项键盘操作；需确认的内容在当前面板可见 |
| 计划及费用批准 | 区分准备、待批准、已提交、运行、未知、失败和完成 | 提交中限制重复动作；焦点仍可到达详情与核对入口，不能用动画代替真实状态 |
| 任务详情 | 未知提交结果可核对原任务；复制失败可仅重试复制 | 错误说明与恢复动作就近；状态不只靠绿色／红色 |
| 弹窗和独立窗口 | 有标题、关闭入口、错误位置；Key 仅在独立安全窗口输入 | 打开后管理焦点；关闭后返回来源。退出不得丢失已提交任务或掩盖未保存草稿 |
| 时间线 | 画面、配音、音乐、字幕四轨；主预览与时间关系同时可见 | 轨道允许必要的横向滚动；缩窄时收起素材区／检查器，保留预览与轨道，快捷键避开文字输入 |

**窗口收缩建议**：以 1440×900 为主要桌面布局检查尺寸，并检查 1100×720。宽窗口可同时显示素材、主工作区和检查器；约 1200px 以下优先收起次要检查器；约 1000px 以下收束全局导航并使用抽屉。具体阈值应在实现时根据内容验证，不能仅依据概念图宣布适配完成。

## 5. 动效分镜建议

以下时间均为本次设计建议，没有从参考站点实测得出。所有动效应服务位置、状态和对象关系，不延迟保存、播放或结果显示。

| 场景 | 开始 → 过程 → 结束 | 建议时长与约束 |
| --- | --- | --- |
| 全局胶囊切换 | 旧项选中 → 选中底片沿同一轨迹移动、文字状态变化 → 新组稳定 | 220ms；可以被下一次选择中断，不能排队播放 |
| 打开项目 | 作品封面 → 同一画面适度扩展，标题和局部导航就位 → 进入项目场景或工作台 | 480ms；只发生在明确打开项目时，避免每次切换都重放 |
| 画布节点出现 | 插入位置占位 → 节点轻微淡入并定位 → 连接端口稳定 | 180ms；批量节点短促呈现，避免逐个长时间飞入 |
| 镜头选中 | 列表／故事板选中 → 当前镜头标识及检查器内容衔接 → 可立即编辑 | 260ms；保留列表位置，不为装饰重新排列全部镜头 |
| 生成与收存 | 准备 → 批准 → 原任务运行及收存 → 结果可审阅 | 由真实状态驱动，不编造百分比；持续进度只在任务运行时使用；重复点击不能触发第二次提交 |
| 检查器开合 | 主工作区保持锚点 → 侧面检查器进入或收起 → 焦点转到相关字段 | 使用与导航一致的短过渡；不拉伸作品画面，不阻挡主编辑区 |
| 审片切换结果 | 当前素材 → 载入反馈 → 新素材显示并保留来源标识 | 仅在实际可显示时交接；不能用淡变掩盖加载失败或错用版本 |
| 剪辑播放 | 用户播放 → 预览与播放头准确更新 → 停止后保持位置 | 播放期间无装饰动效；时间码与播放头不添加缓动 |
| reduced motion | 直接更新位置与选中态 | 静态切换；保留文本、焦点与状态反馈，取消扩展、位移及渐次入场 |

静态图不能验证上述动效、性能、焦点、键盘行为、响应式适配或真实任务状态。实现阶段需要可运行原型，再分别检查这些行为。

## 7. 业务边界与后续验证

- 保留个人 Windows Electron、本机引擎、一部短剧一个工作目录，以及应用级模型配置。
- 父项目共享角色、声音、素材和记忆；子项目承载当集创作。更换UI结构不能改变数据归属。
- 图片入库、绑定实体、选作分镜图、加入画布、用于视频首帧是不同操作，界面应表达实际完成的步骤。
- Agent 与成片助手通过提案及选择采用推进；不会因为视觉改版就获得自动完成全剧能力。
- MCP 当前为 SPEC-004 M1。概念图不代表 M2/M3 的音频、完整时间线、导出和连续记忆工具已交付，不等于 MCP 全链路已经实现。
- 声音试听、克隆、审核与修复保留当前能力边界，不把未映射的情绪／口音参数画成精确控制保证。
- 所有图为静态概念稿；按钮文案和排布需在实现时校对，真实任务／素材／模型效果、完整业务验收及无障碍验收均需另行完成。

建议后续以这18张的导航和版式建立可运行原型，先验证「项目与集期 → 剧本分镜 → 镜头生产 → 对白审核 → 时间线 → 导出」主流程，再确认次级状态。生产代码与权威规格在获准实施后分别更新。
