## 已测到的样式证据

`xiaoyunque/preference-measurements.json` 是本次偏好浮层的计算样式，不代表全站 token：

- `backdrop-filter: blur(40px)`；白色 8% 背景；白色 12% 边框，观测宽度约 0.667px。
- 圆角 24px；阴影 `0 18px 48px rgba(0,0,0,.28)`。
- 观测尺寸 400 × 320px、字体 16px。
- 字体栈：`PingFang SC, Hiragino Sans GB, Microsoft YaHei, Noto Sans SC, sans-serif`。

先在同类背景与内容密度下对照，再适配羊番黑蓝色系。不要把浮层参数套用到所有面板、按钮和卡片；截图中的透亮底色也不等于应该使用浅色实底。

## 新采到的工作台布局发现

- **工作台收窄全局导航。** `13–17` 使用窄图标栏与紧凑项目上下文；留给创作内容的空间明显多于此前羊番的大侧栏与口号头部。羊番可以采用可展开导航，但其展开行为需要自己设计和验证。
- **列表与画布是同一批内容的不同视图。** `13` 是分类资产列表，`14` 切到分组画布；主上下文保持一致。羊番应保留选择和所在短剧，不把切换视图当作切换项目。
- **剧本阅读与 Agent 并列。** `15` 中正文直接排在主背景上，故事设定/分集大纲/剧本正文是内部页签；Agent 在右侧独立面板，输入区停靠底部。羊番应避免正文再套厚重卡片，并预留关闭 Agent 后的阅读空间。
- **分集列表和镜头工作台使用不同密度。** `16` 用横向分集卡聚合封面、状态、角色/场景/镜头数；`17` 则为左资产、中描述、右预览和底部镜头条。不能为追求统一，把两种任务都做成同一网格卡片页。
- **分镜属性围绕当前镜头组织。** `17` 顶部是当前片段和引用资产，中间为描述，右侧视频负责判断结果，底部镜头条负责切换；主动作不需要在四个区域重复出现。羊番仍需保留镜头版本、待审批和采用关系。
- **版本历史是专注预览层。** `19` 将预览、下方版本缩略图、右侧版本编号/时间/描述分开；“替换当前片段”在示例中禁用。可参考布局与信息层级，不能据此声称替换、保存或回退行为已验证。

## 小云雀登录后新增模仿规则

- **素材与语义资产分开。** `xyq-06`、`07`、`09` 的素材库按媒体类型和来源管理文件；`xyq-10`、`11` 的角色库承载角色名称、形象版本、描述与音色。羊番不能把所有资源揉成一个图片瀑布流：媒体文件负责来源与版本，角色/场景等资产负责创作身份与可复用引用。
- **Agent 与画布同屏。** `xyq-20` 显示窄导航、资产入口、空画布和右侧对话，Composer 在右下。羊番可以将 Agent 固定为可收起的右侧工作区；它应作用于当前画布上下文，而不是再开一层独立页面。该图是既有空画布，不证明生成节点、自动排布或写入行为。
- **偏好采用两列参数组织。** `xyq-21` 左列模型及说明，右列比例、分辨率和时长，上方按能力类别切换。羊番借鉴分组与密度，只呈现真实配置支持的模型参数，不照搬会员标签或模型名称；默认输入框内不摊开整套选项。
- **技能用三个层级渐进呈现。** `xyq-22` 为类别 → 技能列表 → 预览说明，并有搜索、收藏和详情入口。羊番先让用户定位任务，再比较技能与说明；不能给每个技能一个同等巨大的发光卡。未实现的创建、收藏等操作不能仅为丰富界面而显示可用。
- **版本与工作台状态仍按证据区分。** `xyq-19` 能支持镜头条与工作台排布；`16`、`17` 有引导/悬浮预览遮挡，仅支持可见节点和上下文区域参考。只读示例和一次选中不等于拖拽、保存、替换或完整编辑行为已验证。

## 本轮未覆盖与打包边界

- 两平台真实运行中、失败及重试状态未采；已有完成任务和历史视频不是本轮生成。
- 完整节点编辑、持久化、回退/替换行为未验证；多轨剪辑详情未采；部分历史会话未逐一穷举。
- 账号、付费、营销活动、移动端及全部响应式状态不属于此次覆盖声明；不声称全站 100%。
- v3 ZIP 只包含 manifest 登记的有效/partial/历史页面、有效组件、样式测量和索引说明。诊断排除图、此前 ZIP 和独立生成的羊番 UI 草稿不混入。
- 索引将“两站公开与历史”“即梦登录后”“小云雀登录后”单列；“小云雀登录后 · 本轮新增”筛选只选 `site=xyq` 且 `phase=authenticated`，不会把即梦登录后页面误算为本轮新增。

## 逐项模仿顺序

1. 以当前已核验截图进入逐组件对照；真实运行/失败、完整编辑节点、多轨剪辑详情及部分历史会话仍列未采。只有相关设计需要时再补缺口，不重复采同状态，也不以新生成内容冒充现有界面证据。
2. 先对照复刻默认输入区、技能/偏好/添加参考浮层；逐项校准空间、字体、选项组织和边界，暂不增加额外装饰。
3. 再校准导航、资产网格、媒体详情与结果操作栏。每个组件保留源截图与实际可见状态，分清参考事实和羊番自己的设计决定。
