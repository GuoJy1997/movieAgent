# 创作工作台 · Motion Study 02

面向 Electron 桌面产品的交互动效样机。完整产品目标仍是自选模型的个人影像工作台，支持内置本机引擎和远程服务器。

## 启动

在本目录运行 `node serve.cjs`，打开 <http://127.0.0.1:5167>。无需安装依赖；停止预览可在启动终端按 Ctrl+C。服务只绑定本机回环地址。

## 体验路径

1. 首页查看电影场景、项目卡片和指针透视效果，点击「进入工作台」。
2. 拖动节点标题，观察连线跟随。用左下角缩放与重置按钮调整画布。
3. 打开资产抽屉，搜索 `portal` 或无匹配词；点击素材回到参考节点。
4. 在创作 Agent 输入框中描述镜头，发送并将草案应用到提示节点。
5. 点击「演示生成」，观察输入、执行、收存和完成状态，以及连线光点和结果显现。
6. 展开时间线，切换全景、细节和主体裁切。节点预览按钮演示静态图片的缓慢推近。
7. 查看模型连接弹窗，或使用右上角「减少动态效果」。

## 实现边界

- 使用真实 HTML 控件、CSS 和 JavaScript；没有用整张 UI 图片遮盖交互。
- `portal.png` 是 Image Gen 生成的独立虚构场景。多个预览是同一素材的裁切。
- 模型请求、Agent 回答、视频生成、持久化、文件导入和 Electron 打包尚未实现。
- Agent 草案是输入文本的规则演示；生成流程使用本地定时器。没有 API 请求、凭据保存或计费。
- 页面导航或刷新会重置样机状态。此代码用于确认视觉与交互，正式产品按完整架构另行接入数据和引擎。
- 所有运行资产都在本目录；Lucide 图标的 ISC 许可证保存在 `assets/LUCIDE-LICENSE`。
