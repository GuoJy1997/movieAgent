# Layers 参考下的视觉与动效方案

2026-10-24。用户要求比 v1 更酷炫，并以 GetLayers 为参考。本文件取代 v1 的保守灰色编辑器方向；完整产品架构与自有模型配置目标保持不变。

## 设计判断与参考诊断

为个人创作者制作 Electron 影像工作台，核心感受是掌控、空间深度与电影感。主要风格为精密的黑银影像设备，以作品本身作为视觉中心。

已在公开预览中查看并捕捉：

- [AI Studio](https://www.getlayers.ai/layer/ai-studio)：金属主体、深色空间、光线与镜头推进。适合启动/进入项目的短过渡。
- [Creative Director](https://www.getlayers.ai/layer/creative-director)：流动暖光、颗粒、作品叙事。适合项目入口氛围；工作区降低强度。
- [Mirror Hall](https://www.getlayers.ai/layer/mirror-hall)：有景深的媒体序列与惯性切换。适合素材选择和镜头浏览。

公开预览能说明视觉与可见运动，不代表已获取付费模板源码或完整参数。样机独立实现，不依赖网站付费素材或服务。

## 分层视觉 brief

背景 L0 为低亮度黑色；L1 为入口页面的暖光与原始媒体；L2 为画布网格/连接；L3 为节点媒体；L4 为正文、工具与检查器；L5 为菜单、审批和对话框。运行中的连接线有定向光点，所有正文表面保持稳定与对比度。强光仅发生在选中/执行/完成，不让全屏同时持续发光。

## 组件与状态

图标侧栏、项目切换胶囊、资产抽屉、四种基础节点、Inspector、Agent composer、时间线抽屉和模态设置。所有控件有 focus-visible、hover、pressed、disabled；任务明确区分正在演示与真实执行。空库、失败、离线和冲突状态将在对应功能实施时补齐。

## 动效分镜

| 触发 | 运动 | 时间 | 实现 | 减少动态效果 |
| --- | --- | --- | --- | --- |
| 首次打开 | 媒体缓慢推近，标题和工具错峰出现 | 720ms，错峰 60ms | transform/opacity | 立即出现 |
| 打开项目 | 同一作品从封面过渡为画布主节点，周边控件分层进入 | 620ms | View Transitions + fallback | 120ms 淡入或即时切换 |
| 卡片指针移动 | 小角度透视和局部反射，移出恢复 | 180ms | CSS variables + transform | 静态高亮 |
| 选择节点 | 细边缘高亮，参数切换 | 180–260ms | CSS transition | 立即切换 |
| 打开抽屉 | 侧向滑入，内部 35ms 错峰 | 280ms | transform/opacity | 立即出现 |
| 开始生成 | 连接线定向光点、节点状态变化 | 跟随任务状态 | SVG stroke/offset | 静态橙色与文字状态 |
| 结果就绪 | 缩略图清晰显现，短促边缘确认 | 420ms | clip/opacity | 直接显示结果 |
| 时间线展开 | 胶片轨道上升、镜头依次出现 | 320ms | transform/opacity | 立即显示 |
| 退出或后台 | 停止氛围与无必要动画 | 立即 | visibility + animation state | 同样处理 |

样机用浏览器原生动画 API 和 CSS 验证节奏；产品实现可保留这套状态驱动结构，复杂编排再引入单一时间线库。所有时长是本产品设计值，不声称等同参考站实现。

## 还原与性能约束

基准 1440×900，最小桌面 1100×720；窄于 1200 收起资产/参数侧栏，窄于 900 以抽屉形式使用。正文至少 13px，主控件至少 36px 高。背景不能降低正文对比度。每屏至多一个氛围媒体层；默认不引入常驻全屏 WebGL。节点拖动不同时运行动画缩放；布局变更与媒体解码分开。

减少动态效果同时响应系统 prefers-reduced-motion 与应用开关；关闭深度、长位移与连续光点，保留状态意义。正式应用在最小化/不可见时停止非必要动画。

## 动效样机范围

prototypes/motion-v2 是可点击的视觉/动效验证，展示入口、画布、抽屉、节点拖动、Agent 草案和任务状态。不会调用模型、扣费或保存真实业务任务，也不是完整 Electron 发行包。

验证重点：页面切换、按钮键盘操作、抽屉关闭、重复触发和路由切换不会残留定时器；减少动态效果不改变状态；响应式无横向溢出；图形连线跟随节点移动。
