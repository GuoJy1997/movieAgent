# V3：界面自身形成视觉与动画

> 已暂停：用户随后明确要求灵感和素材继续取自 GetLayers。本文件记录的 React Bits 方案不再作为当前设计方向，相关样机未构建、未验证、未展示为交付。当前以 GetLayers 候选与素材核验为准。

用户反馈确认：V2 的冲击力依赖预设图片，局部过渡不足；用户替换素材后，界面风格可能消失。本轮直接使用现成动画组件源码制作修订样机，不生成新的 UI 图片。

## 采用的路线

直接复用 React Bits 的 Light Pillar、Dock 和 Star Border，提交固定为 `e12c22192ac7b4b452c5e2feb9b586d74765d696`。Light Pillar 的实时 WebGL 光柱承担背景和指针交互；Dock 的物理弹簧承担工具选择；Star Border 的 Canvas 轨迹承担按钮和活跃输入框。自身布局与工作台数据保持独立。

GetLayers 的公开文档说明完整源码需 Full Stack 访问；本轮没有下载付费模板。React Bits 是 MIT + Commons Clause，允许嵌入应用，限制组件本身的再分发。许可原文保留在 vendor 目录，样机不是组件模板包。

## 视觉约定

铜色光流与烟色玻璃。背景程序化光流独立于项目图片；面板以稳定暗色表面承载文字；入口保留明显可见的动态空间，进入编辑视图后适当降低亮度。素材只占据内容槽位，不影响 UI 色彩、尺寸、边界和动效。

默认无素材；提供空白、混合占位和概念素材三种检查状态。可打开「只看动画」暂时隐藏产品界面，检查背景确实持续运动，也可暂停所有动效观察差异。这些是样机检验工具，不作为正式产品的业务功能。

## 动效与组件

- 背景：Light Pillar 持续流动、指针倾斜、点击光脉冲；不需要图片纹理。
- 导航：Dock 原始弹簧放大、相邻图标联动和点击回弹。
- 操作：Star Border 环绕光迹、悬停加速和点击脉冲。
- 内容：视图切换使用布局进入动画；生成演示仅本地状态，明确标记演示。
- 低动态：背景停在当前帧，Dock 使用静态尺寸，Star Border 替换为同形静态控件；系统减少动态效果也生效。
- 资源：页面不可见时暂停不必要运行；WebGL 不可用时显示明确降级状态。

## 验收

默认空白画面能够独立展示完整视觉；移除或切换图片不改变界面结构；两次无操作截图能看出背景变化；暂停后的两次截图背景不变；Dock 和按钮确有交互响应。验证 1440×900 与较窄视口，不声称已达到任何帧率目标。此轮是可丢弃的视觉验证，不代表完整 Electron 产品完成。
