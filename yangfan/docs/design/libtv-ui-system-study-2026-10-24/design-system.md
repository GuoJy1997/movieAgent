# LibTV Studio 组件与界面设计提案

日期：2026-10-24 · 状态：供评审的设计提案，未获视觉定稿批准。

本轮交付是 UI 研究、组件规格和浏览器中的可交互设计样板。不是 Electron 成品，也未接入生成引擎。既有架构方向继续有效：个人使用、Electron 桌面、内置本机引擎、可连接自部署服务器、自配模型。

## 1. 问题与判断

此前生成图展示了“有素材时的画面”，没有充分定义整个产品的界面。首页、资产、Agent、画布、参数检查器以及各类弹层之间，缺少稳定的密度、层级和交互规则。图片替换后，整体视觉就可能失去支撑。

这次先研究实际界面，再设计可复用的规则。LibTV 共记录 56 个页面/状态，其中 54 个有可观察结果，2 个预览/工具浮层的结果不确定；这不是“所有功能、所有状态已验收”。逐项说明、截图与缺口见 `audit.md` 和样板中的“研究记录”。

### 已观察到的关键点

| 事实 | 设计启发 | 证据 |
| --- | --- | --- |
| 工作台主要是中性灰表面、小图标、13px 控件和细分隔线 | 先统一容器与密度，再加动效 | 05、07、11、35 |
| 同站同时存在文字 tab、下划线 tab、分段控件和过滤 chip | 按信息关系定义四类组件，不统一成一排胶囊 | 16、20、25、29、33 |
| 创建、资产筛选、回收站、角色库的弹层尺寸和布局不同 | 建立菜单、popover、表单 dialog、浏览 dialog 的分别规范 | 05、10、11、13、52 |
| 画布节点默认突出媒体，选中时出现上下文工具 | 参数渐进显示，避免每个节点永久挂表单 | 32、41、42 |
| 实际“故事板”模式是 Agent 与项目素材并排 | 我们必须分别设计 Agent 工作区与镜头清单，不能凭名称推测页面 | 33 |
| 3D 导演台使用对象列表、视口、检查器、时间轴 | 专业编辑器应有独立空间骨架 | 47–49 |

这些是观察与设计推导，不表示复制 LibTV 的源码、品牌、会员体系或所有运营模块。

## 2. 三种可比较的方向

用户要求降低 AI 感、覆盖全部页面层级、保留真实动效。以下是设计者提出的选项，用户尚未选择最终风格。

| 方向 | 具体做法 | 优点 | 代价 |
| --- | --- | --- | --- |
| **石墨工作台（建议）** | 中性深灰、低亮表面、细内缘高光，浅青绿仅用于当前操作 | 适合长时间看片与编辑；空状态、表格和弹层也能成立 | 要靠精确字阶和边界做层次，不能靠背景画面补救 |
| 雾银 | 同一组件几何，浅灰背景、白色浮层、墨色文字 | 日间阅读与设置页清楚，容易看出间距问题 | 媒体预览需要保留深色看片区 |
| 暖灰 | 炭灰表面偏暖、柔和米色强调 | 更接近创作工具的器物感 | 容易过度装饰，须严格限制暖色面积 |

样板中三种材质使用相同布局与相同内容，避免通过不同海报影响判断。主建议由设计者作出，不视为用户批准。

## 4. 视觉基础

### 色彩与表面

提案默认 token：

| token | 石墨值 | 用途 |
| --- | --- | --- |
| canvas | #141617 | 主工作面、画布 |
| shell | #181a1b | 导航、固定栏 |
| panel | #202324 | 卡片、输入组、普通面板 |
| raised | #292d2e | 浮层、激活项 |
| border | #383d3e | 交互控件轮廓 |
| separator | #2b3031 | 内部分隔线 |
| text | #edf0eb | 主文字 |
| secondary | #acb3af | 有意义的次级文字 |
| muted | #929b95 | 补充元数据；不能用于必读错误信息 |
| accent | #d3e8bb | 主动作与选中指示 |
| accent-ink | #243021 | 强调色底上的文字 |
| success / warning / error | #b0d4ab / #e4c383 / #efa29b | 必须同时提供状态词与图标 |

表面由亮度、1px 内缘与短阴影区分。按钮可以有不超过 4% 的上下亮度差，属于材质而非背景插画。普通内容区不使用背景模糊；浮层可以 12px 局部模糊，性能或降低动态模式下有实色回退。

### 字体与空间

- 中文优先系统 UI 字体：Windows 使用 Microsoft YaHei UI / Microsoft YaHei；macOS 使用 PingFang SC。拉丁字符用系统 sans-serif。固定数值采用等宽字体和 tabular-nums。暂不下载商业字体。
- 字号：页面标题 22/30、区块标题 16/24、正文 14/22、控件 13/20、元数据 12/18。画布参数可 12px，但不能将整个应用压到 11px。
- 常规字重 400，选择/标题 500–600；不采用大面积全粗体。
- 间距阶梯 4、8、12、16、20、24、32。页面主边距 28；编辑器内部 12–16。
- 圆角：数值输入 6、按钮 8、popover 12、表单 dialog 16。只有头像、状态点和短分段底座使用全圆角。
- 图标统一 16/18px、同一线宽体系。常规 icon button 命中区 32×32；编辑器允许 28px 高紧凑控件，并保留键盘途径。触控模式增加至至少 44px。

## 5. 页面骨架

| 页面族 | 布局与固定区域 | 页面状态 |
| --- | --- | --- |
| 首页 | 208px 主导航；页头欢迎语/快速创建；最近项目为行式主入口；任务与本机状态为辅助区 | 首次无项目、最近打开、引擎未启动、恢复上次任务 |
| 项目/资产库 | 固定页头、导航 tab、筛选工具栏；网格/列表切换；详情 drawer | 未导入、无筛选结果、有内容、批选、上传中、失败、缺失本地文件 |
| Agent | 会话列表 + 对话主体；底部输入器；需要时打开执行/资产侧栏 | 开始、规划、等待选择、执行、工具失败、断连、完成；真实进度未知要写明 |
| 项目编辑器 | 窗口标题栏 + 文档 tab + 工作区模式；左项目结构、中心画布/镜头/预览、右检查器 | 无节点、选中一项、多选、生成中、离线只读、保存冲突 |
| 镜头清单 | 排序镜头行与版本入口；右侧镜头详情；与画布共享同一项目数据 | 未拆镜、草稿、已生成、待选 take、生成失败 |
| 参数/模型设置 | 二级侧栏，右侧分组设置行；供应方列表及连接详情；不把每项都套卡片 | 未配置、测试中、可用、能力未验证、凭据失效、限流、离线 |
| 预览/专业子编辑器 | 媒体/视口获得大部分空间；对象或轨道列表、检查器、底部时间轴 | 载入、播放、暂停、媒体缺失、导出中/失败 |

3D 导演工具的独立界面规格保留，首期仅建立可扩展骨架；是否实现完整 3D 编辑依照原产品路线，不因为本轮 UI 研究自动扩大开发范围。

桌面最小建议窗口 1100×720。低于 1280px 时 Agent/检查器互斥显示；低于 1100px 提供抽屉并优先保留主工作区。系统缩放 100%、125%、150%、200% 分别验收。不能以整页 CSS 缩放冒充适配。

## 6. 组件目录与状态合同

全部交互组件共用 default、hover、focus-visible、pressed、disabled。选中状态与 hover 分开；禁用提供原因；不靠颜色单独表达状态。下表的尺寸是提案，不是对 LibTV 的测量。

| 组件 | 规格 | 必须覆盖的专有状态 |
| --- | --- | --- |
| WindowChrome | Windows 标题栏 36px；拖动区排除所有控件；原生窗口控制交由 Electron 正确接入 | 最大化、非活动窗、未保存、远程项目 |
| AppSidebar | 默认 208px，范围 184–280；折叠 56；底部固定引擎入口 | active、折叠、长名称、离线 |
| DocumentTabs | 36px；项目名/脏点/关闭按钮；溢出列表 | active、未保存、关闭确认、被移动 |
| PageTabs | 页面内容切换；下划线或平面明暗；独立滚动位置 | 0 项、loading、保留筛选 |
| SegmentedControl | 32px；2–4 个互斥视图；单一滑动指示块 | keyboard、selected、禁用项 |
| FilterChip | 28px；只表达条件；有清除与计数 | applied、组合、无结果 |
| Button / IconButton | 28/32/36px；primary、secondary、ghost、danger | pending 时保留宽度；防重复提交 |
| SearchField | 局部搜索 32px；全局命令 Ctrl+K | composing 中文输入、清空、无结果 |
| Text / NumberField | 输入边界清楚；单位独立；数值支持直接键入、上下键、步进 | 非法值、未提交、范围约束、单位换算 |
| Select / ModelPicker | 普通 select 不等于模型选择器；后者含供应方、能力、连接状态、限制 | 搜索、分组、未验证能力、缺少密钥、不可用 |
| Menu / ContextMenu | 宽 200–280；32px 行；危险操作末组；快捷键右列 | 子菜单、边缘翻转、方向键、Escape |
| Popover | 宽 320–380；锚定触发器；允许说明、搜索、过滤 | max-height、滚动、碰撞回退、关闭焦点 |
| Dialog | 确认 400、表单 560、浏览 960；距视口至少 24px | dirty、提交错误、长表单滚动、返回焦点 |
| Drawer | 右侧 360–440；只覆盖必要工作面 | 暂存、切换对象、键盘关闭；窄窗全宽 |
| Tooltip | 延迟 400ms；不放必须点击的动作 | 长标题、快捷键、禁用原因；可被辅助技术读取 |
| AssetCard / AssetRow | 媒体槽固定比例，名称和状态置于槽外；列表元数据列对齐 | 无预览、音频、broken、selected、missing、uploading |
| EmptyState | 32px 图形 + 一句说明 + 一个相关动作 | 首次空白与过滤无结果不同；不出现虚假最近内容 |
| Skeleton | 固定最终布局几何 | 仅初次载入；低动态静态骨架；避免整页闪烁 |
| JobRow | 标题、阶段、真实进度/未知进度、取消/重试 | queued、running、waiting、canceling、canceled、failed、done、unknown |
| AgentComposer | 文字为主；上下文 chip 可删；模型/模式/能力局部展开 | 草稿、发送中、停止请求、附件失败、超预算待确认 |
| AgentRun | 折叠执行摘要，展开工具事件/产物 | 计划待确认、部分成功、继续/重试、来源链接 |
| CanvasNode | 头部标题 + 类型 + 媒体/内容；选中工具条独立 | idle、selected、running、failed、stale、missing |
| InspectorSection | 分组标题 + 参数行；小分隔；滚动归属清楚 | mixed value、reset、keyframe、validation |
| TimelineTrack | 同步时间标尺、轨道列表、滚动/缩放 | 选片、剪裁、吸附、静音、锁定；本轮仅规格 |
| EngineStatus | 图标 + 文字 + 连接对象；状态和网络地址分开 | local-starting、ready、remote-connecting、offline、unknown |
| Toast / InlineAlert | 可恢复操作后出现；重要错误留在原处 | 带撤销、重复合并、超时暂停、屏幕阅读器提示 |
| CommandPalette | 640px 上限；项目/资产/命令分组；默认不自动执行 Agent | 无结果、键盘导航、最近命令、未配置能力 |
| ResizablePanel | 可抓取 8px 分隔区，视觉线 1px | 拖动、键盘步进、双击复位、边界、布局持久化 |

### 浮层规则

层级提案：基础 0，固定栏 10，画布上下文 20，菜单/popover 40，drawer 50，模态遮罩 70，dialog 80，dialog 内浮层 90，toast 100。Portal 必须继承当前主题 token。

只有模态 dialog 锁定外部交互与循环焦点；非模态 drawer 不随意锁全页。Escape 关闭最上层，焦点回到真实触发器；关闭未修改表单不确认，dirty 表单才确认。危险确认初始焦点在取消。点击外部关闭只能用于无提交风险的临时层。浮层触边时翻转/平移；高度受窗口约束，内容滚动，动作区固定。

### 四种 tab 不能互换

1. 文档 tab 表示同时打开的项目或文件，可关闭、可保留未保存状态。
2. 页面 tab 表示一个页面内的内容分区，使用 aria tablist 与对应 panel。
3. 分段控件是同一数据的互斥显示模式，例如画布/镜头/预览。
4. Filter chip 是可组合的筛选条件，不能用 tab 的行为掩盖多选。

## 7. 自配模型与本机/服务器的界面

用户可添加供应方连接、测试连接、查看实际发现的模型能力，并选择不同任务的默认模型。提供商显示名、API 基址、能力状态和模型 ID 分开保存与显示。不能只出现一个带品牌图标的模型名称。

设置表单顺序：连接名称 → 协议适配类型 → API 基址 → 凭据输入 → 测试 → 能力结果 → 保存。密钥不在列表、toast、日志或截图中明文显示；保存行为由正式引擎的凭据存储能力决定。本轮样板不接收或存储真实密钥。

引擎切换前显示“本机/服务器名称、当前项目位置、未完成任务”。连接失败不立即清空当前项目；任务状态不可确认时显示“连接中断，状态待确认”，不能伪造失败或正常。保存与测试是两个动作，不因输入地址自动发送凭据。

生成前显示任务所需能力；价格可得才给估计费用，否则写“费用未知”。用户明确选择模型与运行方式，不能静默降级到另一家。Agent 提出批量生成时，运行范围与成本估计/未知项一起确认。

## 8. 动效规则

| 场景 | 建议参数 | 目的与限制 |
| --- | --- | --- |
| hover / press | 100 / 80ms；表面亮度变化，按压最多 1px | 及时反馈，列表行不悬浮放大 |
| tab 指示块 | 180ms，cubic-bezier(.2,.8,.2,1) | 让选中位置可追踪；正文不横向飞入 |
| 菜单 / popover | 140ms，opacity + 4px 位移，从锚点展开 | 不旋转、不弹跳；方向随定位变化 |
| dialog | 180ms，opacity + scale .985→1；遮罩 120ms | 保留空间感，禁止长时间等待 |
| drawer | 220ms，水平位移 24px→0 | 展示它与工作区的空间关系 |
| 节点聚焦 | 240ms，平移/缩放一起 | 点击不同节点不累计排队；手动拖动打断 |
| 生成结果 | 220ms 淡入；可选一次 450ms 细粒揭示 | 仅结果到达时触发；素材已存在时不重播 |
| 执行中 | 小范围状态指示持续；真实百分比平滑 160ms | 未知进度不编造百分比，离屏/隐藏窗停止装饰动画 |
| 空首页环境 | 可选低对比光场或线条 12–20s；默认很弱 | 独立于图片，只在空闲首页；编辑器不铺满 shader |

优先 transform 与 opacity。最大同时活动装饰动画 2 个；大量节点生成时用统一时钟/静态状态批量渲染。reduced-motion 下取消位移、缩放、扫描与循环，只保留即时选中和文字状态；应用设置还可进一步关闭动效，不能覆盖系统减少动态偏好。避免闪烁和音效默认开启。

## 9. 样板的范围

`index.html` 展示：三种材质、组件状态板、tab/菜单/模型 popover、确认/连接 dialog、资产 drawer、任务动画、首页/资产/Agent/工作区/设置的页面组合，以及完整研究图库。页面组合都是虚构样例。显示“演示”的任务、连接测试与数据不访问外部 API，不代表实际能力。28 类组件合同不等于本轮已有 28 个生产 React 组件。

本轮不做完整富文本编辑、拖拽节点、剪辑、文件系统访问、真实模型连接或 Electron 打包。组件名和行为合同供后续 React 组件库实现；样板中的轻量 HTML/CSS/JS 不应直接冒充生产组件库。

## 10. 后续实现与验收

建议在视觉方向确认后，独立建立 renderer 的 `ui` 包：tokens → 基础控件 → 浮层与焦点管理 → 页面骨架 → 业务组合。正式基础组件只选择一套可访问的 headless primitive，优先评估 Base UI 与现有 React 架构的兼容性；不要同时拼装多套底层以制造不一致。具体依赖版本在实现时按官方当前文档固定，不在设计阶段臆定版本。

验收顺序：

1. 无任何内容图片时，首页、空资产、空画布、设置页仍有明确主次；换成用户随机素材不影响组件对比度。
2. 同一按钮、popover、dialog、tab 在五类页面中完全共用 token；用真实中文长文、长文件名和大数字验证。
3. 键盘完成导航、选择模型、输入参数、关闭弹层；焦点不可丢失，中文组合输入不触发提交。
4. 覆盖空/加载/离线/失败/部分成功/未知进度/取消处理中；未知与正常不能混淆。
5. 1100×720、1440×900、1920×1080 及系统缩放验证；主区、侧栏和浮层分别滚动，不双重滚动。
6. 动效开/关与 reduced-motion 均可用；测试 500 资产卡、200 画布节点时的交互延迟与帧时间。这是未来性能目标，尚未测量，不能声称已达 60fps。
7. 颜色对比、屏幕阅读器、面板分隔键盘操作及 Electron 标题栏拖动需在正式实现中验收；本轮样板检查不替代这些测试。

下一步只需对“石墨/雾银/暖灰、控件密度、动效强度”作视觉选择；架构和产品用途无需重新问一遍。

本轮已执行的样板检查与限制见 [validation.md](validation.md)。独立规格审阅未发现关键规划缺口。本地样板截图接口未能返回画面，实际检查以键盘交互、可访问树与 DOM 尺寸为依据；像素级视觉验收、动效流畅度和正式 Electron/DPI 测试仍未完成。
