# P3 交付证据索引

本目录保存本次实施的报告、审阅结论、验证记录与实现约定。核心测试、打包界面测试和最终包校验是不同层级的证据，不互相替代。

- [使用说明](../../delivery/2026-10-27-p3-local-desktop.md)：入口、创作步骤与当前边界。
- [验证总表](../p3-creation-agent.md)：执行过的测试、准确发行哈希及未验收项目。
- [实现约定与代价](implementation-decisions.md)：实施中采用的全部重要约定。
- `task-1` 至 `task-4` 的 report/review：各任务的实现结果与审阅修复记录。
- `final-review.md`、`final-fix-report.md`、`final-fix-review.md`：跨模块审阅、最后一轮修复及其复核。
- `progress.md`：实施账本，保留按时间记录的决定和验证范围。
- `*.txt` / `*.json`：保留的命令输出与包检查结果。含 `task-4` 的文件是对应阶段的历史证据；最终发行身份以总表和控制器交付记录为准。

包和媒体测试只使用本地模拟接口及临时资料库。历史界面截图位于本目录的 `screenshots/`，对应总表记录的界面测试哈希；它们不是最终修复版本的再次 GUI 验收。

本地源代码提交保留在 `codex/desktop-foundation`。审阅 diff 可由各报告的起止提交重建，无需将临时 diff 副本作为第二份源码保存。
`*.txt` 测试输出归档仅整理行尾空白和文件末空行，不改变测试结果；启动脚本前后副本保持原内容。
