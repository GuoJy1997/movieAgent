# MovieAgent 本机维护（P5）

适用于 Windows Electron 0.2.0。入口：项目启动器 → 项目维护。工作台顶部也可打开项目启动器。

## 完整备份

1. 关闭需要备份的项目工作台。项目仍被引擎占用时会拒绝操作，不会中断任务或强制关闭窗口。
2. 点击“备份项目”，依次选择短剧项目目录、备份父目录。
3. 等待完成提示。备份是包含 `backup.json` 和 `project/` 的整个文件夹，请成套保留，建议另存到另一磁盘。

备份包含 SQLite 一致快照、全部已登记原件和其他持久对象、剧本/分镜/画布/角色/声音/任务历史，以及项目目录内用户文件和空目录。预览、缓存、临时文件、锁、日志、旧内部备份、系统凭据和客户端待发命令不会复制。成片保存的原件及项目内导出文件会保留。数据库仍保存模型定义及凭据引用，但不包含系统密钥；软件级模型配置需要单独保留，换机需重新填写密钥。用户自行放在项目内的普通文件会原样复制，不进行内容脱敏。

只备份关闭的项目，不提供在线快照。限制：文件和目录合计 100000 项、深度 32 层、单文件 8 GiB、总文件内容 256 GiB、备份清单 16 MiB。拒绝网络路径、目录链接/符号链接、设备名和冲突路径。复制失败留下的目录不应作为完整备份使用；校验不通过时不会创建恢复项目。

## 恢复与启用

填写目标名称，点击“从备份恢复”，选择完整备份目录和目标父目录。只创建新文件夹，不覆盖已有目录。恢复前校验每个文件 SHA-256、数据库完整性、外键和对象引用；恢复时再次核对实际复制字节。

恢复保持资料库、短剧、资产、历史版本和任务身份，但分配新的工作区身份，避免沿用旧客户端待发命令。恢复项目默认暂停任务执行，可以先打开检查。需要继续制作时，关闭恢复工作台，再点击“启用恢复项目执行”，确认原项目在其他电脑/应用中也已停止。重新打开后恢复调度和对账，可能继续调用模型。程序仅能检查本机目录占用，并以启动器配置目录中的身份锁约束本机副本；无法证明另一台电脑已停止。

相同备份恢复到同一已成功恢复且关闭的目标，会返回当前实际状态，不覆盖后续修改，也不改变启用状态。已启用的目标会明确提示仍在启用；已停用或正在打开的目标会拒绝。文件型项目首次打开时的初始化身份会通过它自己的数据库回执验证。未完成的目标目录会明确拒绝覆盖，请保留排查或选择另一个新名称。

## 迁移项目

关闭源项目，填写新位置的目标名称，点击“迁移到新目录”，选择源目录及目标父目录并确认。程序保留一份与目标相邻的完整迁移备份，校验恢复后停用源目录，再启用目标目录。完成后从最近项目打开新位置。

源目录不会删除，旧数据仍可取回，但新版应用拒绝从已停用源目录执行。迁移需要源数据以外两份副本的空间。断电发生在停用源目录之前时，源项目仍可用，目标保持暂停；停用之后目标若尚未启用，可通过“启用恢复项目执行”恢复。不要手工删除维护标记以同时运行多个副本。使用旧版应用不保证识别新版维护标记。

## 手动升级与回退

先备份项目并单独保留模型配置，再退出 MovieAgent。点击“定位本地安装包”仅在文件管理器定位自己已下载的安装程序，不自动运行或下载。由用户运行安装包，保持原应用标识和安装位置。短剧目录是独立数据，不随安装覆盖；卸载配置不删除 AppData。

新版本打开旧数据库前，会在项目内部 `backups/` 保存旧库，使用候选库完成迁移与完整性校验后再替换。迁移失败保留原库和候选证据；完整项目恢复仍以外部备份为准。内部旧库备份不等同于完整素材备份。

回退时用兼容应用把升级前的完整备份恢复到新目录，检查后再启用执行。不要将旧 SQLite 文件单独覆盖新版项目，也不要用旧版强开新版数据库。不支持的未来格式会拒绝读取。

本批不包含自动更新服务、Linux 部署或远程引擎。真实安装覆盖/卸载和跨电脑场景需要在干净系统上另行验收。
