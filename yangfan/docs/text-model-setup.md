# 配置文本模型

启动 MovieAgent，创建或打开一个短剧项目。在左侧进入「模型设置」，点击「新增全局模型」，把模型用途选为「文本模型」。配置保存在软件的 `config/models.json`，不同短剧项目可以共用；剧本、分镜与素材仍分别保存在各自项目目录。

## 接入步骤

1. 选择服务商提供的协议：OpenAI 兼容或 Anthropic 兼容。按照服务商说明选择，不要根据模型名称猜测。
2. 填写 Base URL 和 API Key。地址可以是服务根地址或已有的 `/v1` 地址；自定义网关路径会保留。
3. 点击「获取模型列表」，选择模型。服务商没有列表接口时，直接填写完整 Model ID。
4. 核对「测试连接」按钮上方显示的输出预算和参数，再点击测试。程序发送一次简短文本请求，最多使用所选输出预算，可能产生费用；30 秒超时。
5. 测试返回有效文本后才能点击「保存配置」。保存前修改地址、密钥、协议、模型或生成参数，需要重新测试。

已有条目的 API Key 留空表示沿用原密钥；程序不会把已有密钥显示出来。删除条目或明确清除密钥无需先测试。

## 测试结果如何理解

拉取到模型列表不代表列表里的每个模型都能生成文本：账户权限、余额和模型类型都可能不同，仍需测试所选模型。列表拉取失败也不代表生成接口一定不可用，可以手填 Model ID 后测试。

测试只验证这次请求。以后服务限流、欠费、撤销密钥或模型下线，生成任务仍可能失败。程序不会在测试失败后自动重试付费请求。

测试与正式生成共用「高级设置 → 全局默认参数」中的输出预算，范围为 1–8192，默认 1024 token。按钮上方会随协议、输出长度参数和数值的变化显示当前预算。如果推理耗尽预算而没有可用文本，程序会提示失败；这不等同于密钥无效。可以手动调高同一个输出预算，再明确点击测试；较大预算可能增加费用，程序不会自动加大预算或重试。修改预算也会使旧测试失效，需重新通过后才能保存。

OpenAI 兼容服务对输出长度参数存在差异，可在「高级设置 → 输出长度参数」中选择服务支持的 `max_completion_tokens` 或 `max_tokens`；Anthropic 使用 `max_tokens`。测试与保存后的正式生成沿用相同参数和数值。Anthropic 响应中合法的推理或隐藏推理块会被忽略，只保留最终文本；只有推理、没有最终文本，或包含工具及不支持的内容块，仍会测试失败。

使用本机或局域网服务时，需要明确允许私有地址。不要把 `/models`、`/chat/completions` 或 `/messages` 这样的具体请求接口当作 Base URL；填写它们上一级的 API 基础地址。

目前支持 OpenAI Chat Completions 和 Anthropic Messages 的基础文本请求。只有 Responses API 的服务或要求额外专用认证头的网关，需要另行适配。
